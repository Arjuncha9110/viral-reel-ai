# Divine Panchang Standalone Page

This prototype is intentionally separate from the travel reels tooling.

Files:

- `index.html`: standalone landing page for Divine Panchang

Suggested use:

1. Keep the current main site intact.
2. Deploy this page as a separate route such as:
   - `/daily-guidance`
   - `/today`
   - `/watch`
3. Replace the placeholder YouTube and Instagram links in `index.html` with the real channel/profile URLs.
4. Once the content direction is validated, merge the sections into the production site repo instead of the reel app repo.
